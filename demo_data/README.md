# Demo files for Predict from CSV

Generated by `python scripts/10_make_demo_data.py` from the 2012–2015 test years, which no model saw in training. They show the upload working on held-out data. They are not new evidence: the same rows are already in the project's test set.

Rows with an imputed farm figure are left out (316 of 1766 test rows), because their stored ratios cannot be recomputed from the raw figures.

To try a file, open the app's Predict from CSV page and upload it.

| File | Rows | What it shows |
|---|---|---|
| `demo_jharkhand.csv` | 96 | Every usable district-year from Jharkhand. Includes actual yield, so accuracy is reported. FedPer predictions should match the project's frozen test predictions. |
| `demo_punjab.csv` | 74 | Every usable district-year from Punjab. Includes actual yield. |
| `demo_kerala.csv` | 47 | Every usable district-year from Kerala. Includes actual yield. |
| `demo_mixed_states.csv` | 29 | Three districts each from irrigated Punjab, high-rainfall Kerala, semi-arid Maharashtra and West Bengal. Each row is predicted with its own state's model. |
| `demo_no_yield.csv` | 29 | The four-state file with the actual_yield column removed: predictions without accuracy figures. |
| `demo_all_states.csv` | 118 | 2 districts from each federated state that has usable test rows, every test year. Shows the per-state models side by side. |
| `demo_with_errors.csv` | 13 | Six valid rows, then: a Telangana row (no model), a misspelt state, a missing July rainfall, text in a number column, a rice area below 2,000 ha, an extreme July rainfall (accepted with a warning) and a 2005 row (accepted, flagged as a training year). |
